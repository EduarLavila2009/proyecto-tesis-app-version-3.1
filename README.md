# MEDICAL corp

Aplicación móvil para el proyecto de tesis:
**"Construcción de un Robot Mecánico Médico Personal para la asistencia de la salud pública integral haciendo uso de la Inteligencia Artificial"**

## Tecnologías

- Expo SDK 54
- React Native
- React Navigation (Stack Navigator)
- AsyncStorage

## Instalación

```bash
cd medical-corp-app
npm install
npx expo start
```

## Estructura del proyecto

```
src/
├── screens/       # Pantallas de la aplicación
├── navigation/    # Configuración de navegación
├── components/    # Componentes reutilizables
└── constants/     # Constantes (colores, storage keys)
```

## Funcionalidades (Fase 1)

1. **Selección de rol** - Paciente o Doctor
2. **Login** - Inicio de sesión con validaciones
3. **Registro** - Crear cuenta (datos guardados localmente)
4. **Menú principal** - Bienvenida, perfil, cerrar sesión

## Uso

1. Abre la app y selecciona tu rol (Paciente o Doctor)
2. Si no tienes cuenta, regístrate
3. Inicia sesión con tu correo y contraseña
4. Explora el menú principal

---

Proyecto académico - Sin backend ni base de datos externa.
